# Scratch_Snake_game
Classic snake game built as my problem set 0 project for CS50x. 


A classic Snake game developed as a learning project to strengthen programming fundamentals and game logic concepts.
This project is a simple implementation of the Snake game, created to understand how loops, conditions, and state management work together in an interactive program. The focus of the project is correctness, clarity, and learning rather than advanced graphics or optimization.

-Features
 Continuous snake movement using a loop
 Food generation and growth mechanism
 Collision detection with boundaries and snake body
 Game over condition on self-collision
 Increasing difficulty as the game progresses

-Purpose
The primary goal of this project is to build a strong foundation in logical thinking and program structure. This project serves as a my problem set 0 solution for CS50x.

-Learning Outcome
Through this project, I gained practical experience in translating game rules into code and managing program flow in a structured way.
